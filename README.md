A two-line robot confession: one sentence owning a specific mistake, one naming the lesson and the fix.

- **Line 1:** the robot apologizes for watering the plastic fern every morning for a month while the real basil wilted beside it.
- **Line 2:** the lesson it drew — touch a leaf before pouring, because shine is not the same as thirst.

`main.py` copies the pre-written `entry.txt` into `MAKEFUN_OUTPUT_DIR` unchanged.
